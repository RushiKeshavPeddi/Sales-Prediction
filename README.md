# Salary Prediction MLOps

## Project Overview

This project implements a machine learning and MLOps workflow for Salary Prediction.

The project includes data preprocessing, feature engineering, model development, experiment tracking, and version control.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- MLflow
- Jupyter Notebook
- Git
- GitHub
- DVC

## Project Structure

- data/ - Dataset files
- models/ - Trained machine learning models
- reports/ - Reports and analysis
- src/ - Source code
- .dvc/ - DVC configuration
- .gitignore - Git ignored files
- .dvcignore - DVC ignored files
- README.md - Project documentation

## MLOps Tools

### Git and GitHub
Used for source-code version control and remote repository management.

### DVC
Used for dataset version control.

### MLflow
Used for machine learning experiment tracking.

## Workflow

1. Load the salary dataset
2. Perform data preprocessing
3. Perform feature engineering
4. Train machine learning models
5. Evaluate model performance
6. Track experiments using MLflow
7. Store models and reports
8. Version project files using Git and DVC

## How to Run

Install the required packages:

pip install pandas numpy scikit-learn mlflow jupyter dvc

Start Jupyter Notebook:

jupyter notebook

Run the notebook cells in sequence.
